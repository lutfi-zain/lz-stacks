# Skill Forge

A meta-utility to identify repeated workflows in your agent conversations and package them into standard, trigger-optimized agent skills.

## When to Use
- **Discovering opportunities:** Scan chat history to find tasks repeated 3+ times.
- **Packaging workflows:** Convert a successful conversation thread into a reusable skill.
- **Drafting skill structures:** Write the YAML frontmatter and skeleton rules.
- **Refactoring/Merging:** Audit existing skills to resolve overlap or trigger conflicts.

## Core Workflows

### 1. Skill Discovery (Opportunity Scan)
- Analyzes recent chat logs using text scans and semantic clustering.
- Proposes candidates ranked by leverage (Frequency × Execution Time).
- Identifies tasks that should **NOT** be skills to prevent skill bloat.
- Load `./references/opportunity-scanning.md` for details.

### 2. Skill Building
- Converts a workflow spec or conversation transcript into a structured skill.
- Generates the standard `SKILL.md` layout.
- Optimizes descriptions with 5+ trigger phrases to ensure the agent invokes it correctly.
- Load `./references/skill-anatomy.md` for structural anatomy and rules.

## Output Anatomy
Every skill generated by the forge must use this exact structure in `SKILL.md`:
```yaml
---
name: kebab-case-name
description: >
  [Trigger-optimized description containing 5+ specific trigger keywords
  and instructions for the agent to self-invoke]
license: MIT
---
```
