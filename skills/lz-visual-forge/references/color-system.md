# Color System & Gradient Reference

Color is the single most powerful tool for establishing brand identity and directing user attention. The `lz-visual-forge` color system defines strict guidelines for palette construction, visual weight distribution, accessibility contrast compliance, and advanced gradient rendering within Satori's environment.

---

## 1. Palette Construction & The 60-30-10 Rule

A premium palette balances neutral background shades with vibrant foreground elements. To prevent visual chaos, all templates must distribute their color assets using the **60-30-10 Rule**:

1. **60% Dominant Base**: The background of the canvas. Usually dark obsidian, deep charcoal, soft off-white, or minimal gray.
2. **30% Structural Secondary**: Containers, cards, text block boundaries, borders, and main body typography. This color bridges the background and the accents.
3. **10% Accent Highlight**: High-contrast colors reserved strictly for callouts, core metrics, focal icons, and call-to-action badges.

## 3. Contrast Ratios & Accessibility (WCAG AA / AAA)

Any graphic generated by Visual Forge must remain legible across devices. Ensure that text-to-background contrast satisfies Web Content Accessibility Guidelines (WCAG).

### Contrast Guidelines
* **Large Text** (18pt/24px or larger, bold): Minimum contrast of **3:1** (WCAG AA Large) or **4.5:1** (WCAG AAA Large).
* **Body / Small Text** (under 18pt/24px): Minimum contrast of **4.5:1** (WCAG AA) or **7:1** (WCAG AAA).

### Text Layer Color Selection Matrix
To keep colors clean and readable on dark backgrounds (`#090A0F` to `#161923`), follow this text layering hierarchy:
* **Primary Text**: Use near-white values like `#F8FAFC` or `#FFFFFF` (100% opacity).
* **Secondary Text**: Use `#94A3B8` or `#CBD5E1` (70–80% opacity) to create depth.
* **Muted Metadata**: Use `#64748B` or `#475569` (50% opacity) for timestamps or border elements.

## 4. Gradients in Satori

Satori compiles CSS gradients into SVG `<linearGradient>` and `<radialGradient>` definitions. While powerful, the gradient parser in Satori is less forgiving than a modern browser engine.

### Linear Gradients
* **Standardize Direction Directions**: Avoid complex degree angles (e.g., `linear-gradient(132deg, ...)`). Instead, use standard direction keywords which compile flawlessly:
  - `to right` (Horizontal)
  - `to bottom` (Vertical)
  - `to bottom right` (Diagonal)
* **Define Color Stops Explicitly**: Always specify percentages for your color stops to guarantee correct interpolation.

```css
/* Recommended Premium Gradient Syntax */
background-image: linear-gradient(to bottom right, #6366f1 0%, #a855f7 50%, #ec4899 100%);
```

### Radial Gradients
Satori supports radial gradients, which are essential for creating background glows or spotlight effects.
* Use simple circle declarations focused at specific coordinates:
```css
/* Spotlight Background Glow */
background-image: radial-gradient(circle at 50% 0%, #1e1b4b 0%, #030712 70%);
```

## 5. Simulating Mesh Gradients (Workaround)

Modern luxury UI often utilizes organic, multi-colored "mesh" gradients. Because Satori does not support native CSS mesh gradients or SVG mesh patches, you must simulate them.

### Method: Layered Radial Glows
To simulate a multi-colored mesh, stack multiple absolute-positioned radial gradient divs with low opacity and optional SVG blur filters.

```html
<!-- Root Canvas Context -->
<div style="display: flex; width: 1200px; height: 630px; position: relative; background-color: #050508; overflow: hidden;">
  
  <!-- Gradient Glow 1 (Indigo - Top Left) -->
  <div style="position: absolute; top: -200px; left: -200px; width: 600px; height: 600px; border-radius: 500px; background-image: radial-gradient(circle, rgba(99, 102, 241, 0.25) 0%, rgba(99, 102, 241, 0) 70%);"></div>

  <!-- Gradient Glow 2 (Rose - Bottom Right) -->
  <div style="position: absolute; bottom: -200px; right: -200px; width: 700px; height: 700px; border-radius: 500px; background-image: radial-gradient(circle, rgba(244, 63, 94, 0.2) 0%, rgba(244, 63, 94, 0) 70%);"></div>

  <!-- Gradient Glow 3 (Amber - Center Spotlight) -->
  <div style="position: absolute; top: 150px; left: 350px; width: 500px; height: 500px; border-radius: 500px; background-image: radial-gradient(circle, rgba(245, 158, 11, 0.15) 0%, rgba(245, 158, 11, 0) 60%);"></div>

  <!-- Main Content Layer -->
  <div style="position: absolute; top: 0; left: 0; width: 1200px; height: 630px; display: flex; flex-direction: column; padding: 80px; justify-content: space-between; z-index: 10;">
    <!-- Content goes here -->
  </div>
</div>
```

This structural workaround creates a smooth, multi-tonal backdrop that feels deeply immersive and premium, while remaining 100% compatible with Satori's vector rendering engine.
