# YouTube Content Engine

A unified methodology to ideate, outline, package, and repurpose YouTube video content.

## When to Use
- **Planning YouTube schedule:** Generate search and browse video plays.
- **Outlining video structures:** Build retention-aware outline skeletons.
- **Designing packaging:** Generate title + thumbnail-word pairs using the pairing principle.
- **Repurposing long-form:** Extract standalone shorts/clips from longer transcripts.

## Core Modules

### 1. Ideation (Search vs. Browse)
- **Search Plays:** Target evergreen search terms that rank over time.
- **Browse Plays:** Target browse/suggested feeds, leveraging curiosity and current momentum.
- Load `./references/ideation-system.md` for the full methodology.

### 2. Packaging (The Pairing Principle)
- **Title:** Sets search/browse context, includes keywords, targeted at the algorithm. Under 60 characters.
- **Thumbnail Words:** 1-3 words max. Creates human curiosity, contrast, or cognitive dissonance.
- **Rule:** The title and thumbnail words must NEVER echo or duplicate each other.
- Load `./references/packaging-system.md` for generation and critique modes.

### 3. Long-form Outline
- Retention-focused structural skeleton:
  - **Cold Open (0:00-0:30):** Climax-led promise hook.
  - **Setup (0:30-1:30):** Establish the stakes.
  - **Body (3-5 sections):** Each section must build toward and deliver a concrete payoff.
  - **Synthesis:** Tie the through-line together.
  - **CTA:** Single action tied to your monetization goal.
- Load `./references/long-form-structure.md` for outlining.

### 4. Long-to-Short Repurposing
- Extract 5-7 standalone clippable moments from your long-form video.
- Each short must stand completely alone, using climax-led openings.
- Load `./references/long-to-short-repurpose.md` for clippable moment templates and sequencing.
