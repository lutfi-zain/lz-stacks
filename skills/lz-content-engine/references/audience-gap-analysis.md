# Audience Gap Analysis

A pre-publish quality check. This framework surfaces the silent questions your audience asks while consuming your content and details how to address them.

## The Silent Questions
Every time a reader consumes your content, they have internal objections, confusion, or doubts that they do not voice. If these are left unanswered, the content fails to convert or build trust.

---

## The 3-Step Analysis

### 1. Identify the 3 Silent Questions
Read your content draft from the perspective of a highly skeptical target reader. Identify three core questions they will wonder:
- *Q1 (Skepticism):* "Does this actually work in my specific industry?"
- *Q2 (Clarity):* "What exactly does step 3 look like in practice?"
- *Q3 (Friction):* "How long will this take to set up?"

### 2. Determine the Action for Each Question
For each identified question, choose one of these three remediation paths:
- **Option A (Patch the content):** Edit the draft to answer the question directly. Use this if the gap weakens the current post.
- **Option B (Next Post):** Leave the gap, but draft a follow-up post hook specifically to answer it. Use this if the question is too deep for the current post limit.
- **Option C (Pre-write Engagement):** Write a detailed comment reply to this question. Post it immediately when someone inevitably asks it in the comments to boost early engagement velocity.

### 3. Call the Biggest Gap
Identify which of the three questions is the most critical threat. If unanswered, does it make the whole post feel like snake oil or too difficult? Patch this gap first before publishing.
