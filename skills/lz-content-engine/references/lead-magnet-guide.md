# Lead Magnet Guide

A framework to turn content topics into specific, high-converting lead magnets (freebies) that link your content to your paid offers.

## Specificity vs. Generics
- **Generic (Fails to convert):** "Download my free PDF checklist."
- **Specific (High conversion):** "The 12-point checklist I run in my terminal before pushing a new cloudflare worker to production."

---

## Grading Lead Magnet Ideas
When ideating freebies, grade each on two axes:

1. **Lead-Gen Power (High/Medium/Low):** How desperately does your target audience want this specific problem solved? Does it target a major pain point?
2. **Effort to Build (Time estimate):** Can you assemble this from existing assets, or do you have to write a 50-page guide from scratch?

### The Quick Win
The ideal lead magnet has the highest lead-gen-to-effort ratio. Look for existing assets, code templates, swipe files, or summaries you have already built for yourself and package them.

---

## ManyChat Keyword Funnels
For Instagram, the lead magnet must be tied to a comment trigger keyword:
- Pick a short, simple word (e.g., "DEPLOY", "CALENDAR", "BRIDGE").
- Avoid words that autocorrect easily.
- Instruct the user to comment that word in your post caption.
- Set up automation to DM the link immediately upon trigger.

---

## Lead Magnet Structure
Every downloadable lead magnet must include:
1. **Cover Page:** Clean layout using your **Carousel Design System** principles.
2. **The 1-Page Setup:** Explain exactly what this tool is and how to use it in 60 seconds.
3. **The Core Asset:** The actual value (the checklist, the template, the code snippet).
4. **The Natural Next Step:** A single CTA on the final page directing the user to your paid service, newsletter, or audit booking.
