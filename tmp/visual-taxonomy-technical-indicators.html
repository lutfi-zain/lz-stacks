10 Families Principals Statistik

1

Smoothing / Moving Averaging

Convolution dengan berbagai weighting scheme. Trade-off fundamental: smoothness vs lag. Dari uniform weights (SMA) ke exponential (EMA) ke negative weights (DEMA/TEMA) ke nonlinear adaptive (Hull, MAMA).

SMAEMAWMA DEMATEMA Hull MAALMA KAMAFRAMAMAMA

Classical · Sejak 1900-an

2

Digital Signal Filtering

Isolasi frequency band dari price signal. Low-pass = trend, High-pass = momentum, Band-pass = cycle. IIR (recursive, EMA-like) vs FIR (non-recursive, stable). Filter design: Butterworth, Chebyshev, Bessel, Elliptic.

ButterworthChebyshev Ehlers Supersmoother BandpassHighpass LowpassRoofing Filter

Classical · DSP untuk Trading (Ehlers sejak 2001)

3

Regression / Curve Fitting

Fit mathematical curve ke price data. Deviation dari curve = signal. Linear → polynomial → robust (RANSAC) → regularized (Ridge/LASSO/Elastic Net). Bisa auto-select fitur yang berguna.

Linear Regression Polynomial Regression RANSAC RidgeLASSO Elastic NetMCP

Classical · Auto-select indicators via penalized regression

4

Spectral Analysis / Cycle Detection

Decompose price ke komponen frekuensi. FFT (butuh banyak data) → MESA (bisa dari sedikit data) → Hilbert Transform (instantaneous frequency) → Wavelet (time + frequency simultaneous) → EMD (data-driven).

FFTMESA Hilbert Transform Wavelet (CWT/DWT) Empirical Mode Decomposition Autocorrelation Periodogram

Frontier · Ehlers' DSP Framework

5

Fractal / Hurst Analysis

Measure long-term memory dan self-similarity. H=0.5 random, H>0.5 trending (persistent), H<0.5 mean-reverting (anti-persistent). Multifractal analysis captures varying complexity across scales.

Hurst Exponent R/S Analysis DFA Fractal Dimension FRAMA Multifractal (MFDFA)

Frontier · Hydrology → Finance crossover

6

Volatility Clustering (GARCH Family)

Volatility cluster: high vol → high vol, low vol → low vol. Stylized fact #1 financial markets (Mandelbrot 1963). GARCH(1,1): conditional variance = weighted avg of long-run var, past var, past shock. EGARCH/GJR: capture leverage effect.

ARCHGARCH(1,1) EGARCHGJR-GARCH IGARCHFIGARCH Component GARCH

Core Theory · Predict uncertainty, not direction

7

Information Theory / Entropy

Measure uncertainty dan information content. Shannon Entropy tinggi = chaotic, rendah = ordered. Approximate Entropy = market efficiency indicator. KL Divergence detect regime changes. Permutation Entropy = robust to noise.

Shannon Entropy Approximate Entropy (ApEn) Permutation Entropy KL Divergence Transfer Entropy Wavelet Entropy

Modern · Shannon 1948 → Finance applications

8

Nonlinear Dynamics / Chaos Theory

Market mungkin apparent random tapi deterministic chaos — sensitive to initial conditions, bounded dalam strange attractor. Lyapunov Exponent > 0 = chaotic. Fractal Dimension = complexity. Phase space reconstruction via Takens' theorem.

Lyapunov Exponent Correlation Dimension Phase Space Reconstruction Strange Attractors BDS Test

Controversial · Evidence mixed, intermittent chaos likely

9

Bayesian Probabilistic

Model hidden states dari observables. HMM: probabilistic regime classification (72% bull, 20% chop, 8% bear). Kalman: linear Gaussian state estimation. Particle Filter: nonlinear, non-Gaussian extension. Adaptive HMM: two-layer hierarchy.

HMMKalman Filter Particle Filter Statistical Jump Model Adaptive Hierarchical HMM

Modern · Regime detection frontier

10

Machine Learning Hybrids

Combine multiple principles via learned representations. Autoencoder untuk denoising, CNN untuk spatial features, LSTM untuk temporal patterns, Clustering untuk regime detection. Model figure out which combination works.

LSTM-CNNAutoencoder + GAN K-means Clustering XGBoost Ensemble RL + HMM (PPO/SAC) Transformer-based

Cutting Edge · 2020-an, rapidly evolving

Proposed Skill Development Architecture

4-Layer Indicator Development Pipeline

Layer 1 — Input Processing
Denoising (Wavelet, Supersmoother, Kalman) · Normalization (Z-score, Min-Max, Rank) · Feature Extraction (OHLC → returns, log returns, ranges)
Layer 2 — Core Principle Selection (pick 1-2 families)
Smoothing → Filtering → Regression → Spectral → Fractal → GARCH → Entropy → Chaos → Bayesian → ML Hybrid
Layer 3 — Signal Generation
Threshold (RSI > 70) · Crossover (fast × slow MA) · Probability (HMM > 80%) · Divergence (price vs indicator) · Composite (multi-family score)
Layer 4 — Validation
Walk-forward · Out-of-sample · Monte Carlo · Regime-aware (bull/bear/chop separately) · Robustness (parameter sensitivity)

Contradictions Resolved

DSP Cycle Approaches: Ehlers' BandPass shows strong theory but mixed independent backtests. Short cycles (25-35 bar) → negative Sharpe. Wide bandwidths (30-70 bar) → positive. Ehlers himself says "backtesting does not work" — his tools are measurement, not signals.

→ Resolution: DSP filters = adaptive parameter providers, not standalone signal generators.

HMM Regime Lag: HMM outperforms buy-and-hold but lags regime switches. Statistical Jump Models (JM) beat HMM: 44% vs 141% turnover, better Sharpe across S&P 500, DAX, Nikkei 225.

→ Resolution: Consider JM or Adaptive HMM. Never rely on regime detection alone.
