# Caption + CTA Guide

This asset serves as a guide for drafting social media captions and routing Calls to Action (CTAs) to platform-native conversion mechanics.

## Platform CTA Routing Table

| Platform | Recommended CTA Mechanic | Execution Example |
|---|---|---|
| **Instagram** | ManyChat comment trigger keyword | *"Comment 'SHEET' and I'll DM you the link."* |
| **LinkedIn** | Direct link in caption body | *"Get the source code here: [URL]"* |
| **Twitter/X** | Retweet request + link in final thread tweet | *"If this was useful, RT the first tweet. Link below:"* |
| **TikTok** | Comment-bait or "Link in Bio" prompt | *"Get the template from the link in my bio."* |

---

## Caption Structure Blueprint

### 1. The Hook (Line 1)
- Must be climax-led and fit before the platform's fold limit.
- **LinkedIn fold:** ~210 chars | **Instagram fold:** ~125 chars.
- Do not use corporate pleasantries or generic intros.

### 2. The Body
- Short paragraphs (1-2 sentences max).
- Use whitespace for skim-readability.
- No excessive emojis. Use only if aligned with the brand voice.

### 3. The Call to Action
- Make it simple and direct.
- Only ONE action allowed per post.
