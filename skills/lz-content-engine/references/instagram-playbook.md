# Instagram Playbook

A research-backed reference for writing and formatting high-converting content on Instagram.

## 1. Algorithm Insights (2025/2026)
- **Saves & Shares First:** The algorithm prioritizes content that users save (high reference value) or share via DMs. Likes are the weakest signal.
- **Carousel Swipe Rate:** If a user scrolls past a carousel, Instagram will show it to them a second time in their feed, but displaying the **second slide** instead of the cover. Make sure Slide 2 is visually compelling.
- **ManyChat Integration:** Comments containing specific keywords trigger instant DM automations. Posts leveraging this mechanic see up to 5x higher conversion rates than bio link clicks.
- **Reels Retention:** Reels require a visual pattern interrupt or hook in the first 1.5 seconds to prevent the user from swiping away.

---

## 2. Formatting Specifications
- **Dimensions:**
  - **Portrait Feed (Carousels/Posts):** 1080x1350 pixels (4:5 ratio). Do not use square (1080x1080) if you can avoid it, as portrait covers more screen space.
  - **Reels/Stories:** 1080x1920 pixels (9:16 ratio).
- **Caption Limit:** 2,200 characters.
- **The Fold:** The hook must fit in the first 125 characters before the caption truncates and displays the "more" option.

---

## 3. Carousel Architecture
Every multi-slide post must guide the user's eye and thumb:
- **Slide 1 (The Cover):** Climax-led headline, bold display typography, high contrast.
- **Slide 2 (The Hook Payoff):** Instantly deliver on the cover's promise.
- **Slide 3-N (The System):** Explanatory diagrams, templates, or lists. Keep text minimal.
- **Final Slide (The CTA):** Explicit call to comment a keyword (ManyChat trigger) or save the post.

---

## 4. Reels Copywriting and Structure
- **Length:** Keep Reels between 15-45 seconds for maximum completion rate.
- **Format:** Hook first (on-screen text + voiceover) → 3 quick value beats → Call to read the caption.
- **Caption Focus:** Use the Reel's visual to capture attention, and deliver the actual deep-dive text in the caption. Always end the caption with a ManyChat keyword prompt.
