# Long-to-Short Repurposing

A workflow to extract 5-7 high-performing short-form video scripts (Reels, TikToks, Shorts) from a single long-form YouTube video.

## The Standalone Test
Not every part of a long-form video works as a short. To be clippable, a segment must pass the **Standalone Test**:
- *Can a viewer understand the value, context, and lesson in 45 seconds without having watched any other part of the video?*
- If the segment requires prior context or definitions, cut it.

---

## Repurposing Workflow

### 1. Identify the Moments
Review the long-form outline or transcript and mark 5-7 key value beats, stories, or demonstrations.

### 2. Draft the Shorts
For each identified moment, structure a short script:
- **The Opener:** A climax-led one-liner (using **The Bridge Method**).
- **The Body:** 3 quick, punchy beats. Keep copy minimal.
- **The CTA:** Platform-native call to action (e.g., ManyChat keyword or link click).
- **Timestamp:** Note the original YouTube source timestamp for easy clipping references.

### 3. Posting Sequence
Organize the clips into a weekly sequence. Avoid posting similar formats or topics back-to-back. Alternate between code walkthroughs, conceptual takes, and case study clips.
