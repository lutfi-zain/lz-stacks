# YouTube Long-form Structure

A retention-aware blueprint to design outlines for YouTube videos, preventing sags and maintaining audience retention.

## 1. Video Outline Components

### Core Promise
State the singular outcome the viewer gets by watching. This is the spine of the video; every section must serve this promise or be deleted.

### Cold Open (0:00-0:30)
- Front-load the climax. Start in the middle of the action or detail the core result immediately (using **The Bridge Method**).
- Establish the promise of the video.

### Setup (0:30-1:30)
- Establish the stakes: why does solving this problem matter? What happens if they ignore it?

### Body (3-5 Sections)
- Break the lesson down into sequential steps.
- **Section Rule:** Every section must build toward and deliver a concrete payoff (e.g., code snippet execution, a metric result, a takeaway). Do not end a section on setup.

### Synthesis
- Synthesize the through-line. Connect all the steps into a single, cohesive framework.

### CTA (Call to Action)
- A single action request (e.g., link in description, sub for next week).

---

## 2. Retention Notes Check
Identify specific points in the outline where viewers are likely to drop off (e.g., during transition to a technical section or code block) and design the **hold**:
- *Sag Point:* Transitioning from theory to database setup.
- *The Hold:* Show the database layout on screen immediately and state: *"If you get this configuration wrong, the application will timeout under load. Here is the 1-line fix."*
